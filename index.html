D2

O programa para Windows: tela mais estável, sem o navegador no meio, e sempre atualizado sozinho.

Baixar para Windows

Por enquanto o programa é só para Windows. Neste aparelho, use o D2 no navegador.

  1. Abra o D2-Setup.exe que foi baixado.
  2. Se o Windows mostrar "O Windows protegeu o computador", clique em Mais informações e depois em Executar assim mesmo. Esse aviso aparece porque o programa ainda não tem assinatura digital paga.
  3. Pronto: o D2 abre sozinho. Entre com a sua conta do Discord.

Windows 10 ou 11, 64 bits. Prefere não instalar? Use o D2 no navegador.
